# Personal Profile for My Business

This is the official public website for **Darmigan Baskar** — Creative Technologist, AI/IoT Developer, and Founder of **Flash Force 3D Printing**.

## What's inside

- `profile.html` — The main interactive portfolio (Three.js 3D background, mouse follower, 3D profile card, project showcase, contact modal, and direct links to the 3D printing business site)
- `flashforce3d.html` — The dedicated Flash Force 3D Printing business website (equipment showcase, instant quote calculator, materials catalog, and direct order buttons)
- `index.html` — GitHub Pages entry point (same content as `profile.html`)

## Features

- Three.js interactive 3D background
- Custom mouse follower and trail particles
- 3D tilt profile card
- Flash Force 3D Printing business showcase
- Instant 3D printing quote calculator
- Direct Gmail order composer
- GitHub repo / ZIP download link
- LinkedIn, Instagram, GitHub, Devpost, and Discord links

## Tech stack

- HTML5, CSS3, JavaScript
- Three.js r128 (via cdnjs)
- Google Fonts: Syne, Instrument Sans, JetBrains Mono
