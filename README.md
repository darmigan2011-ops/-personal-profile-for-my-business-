# Darmigan Baskar — Personal Portfolio

Personal portfolio website for Darmigan Baskar, featuring creative technology, AI/IoT projects, engineering work, and Flash Force 3D Printing.

## Included

- `index.html` — main personal portfolio
- `flashforce3d.html` — Flash Force 3D Printing page

## Deploy

This is a static HTML website and can be deployed directly with GitHub Pages from the repository root.

AI tools were used during parts of the development process for brainstorming, debugging, code assistance, and iteration. The content, project direction, personal information, design decisions, and final website were reviewed and customized by me.
